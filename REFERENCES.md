# Technical References

ProjectMoyle benefits from public technical documentation, research, and
other projects in the PlayStation preservation and recompilation community.

Useful references consulted during development include:

- [PSX-SPX](https://psx-spx.consoledev.net/) - detailed PlayStation hardware
  and software documentation.
- Sony PlayStation / Psy-Q documentation, where lawfully available.
- MIPS R3000A / MIPS I architecture documentation.
- [PSXRecomp](https://github.com/RetroPortingToolKit/psxrecomp) - a
  general-purpose PlayStation static-recompilation project and a useful
  technical reference for recompilation approaches.
- Other emulator, recompilation, preservation, and reverse-engineering
  projects where specifically acknowledged.

These projects and documents are credited as references because they are
valuable sources of technical knowledge and prior work.

Third-party source code incorporated into ProjectMoyle, if any, is documented
separately in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) together with
its applicable license and attribution.
