# Technical References

ProjectMoyle development makes use of public technical documentation and
reference implementations to understand PlayStation hardware, software,
and static-recompilation techniques.

References may include:

- PSX-SPX / nocash PlayStation technical documentation
- Sony PlayStation / Psy-Q documentation where lawfully available
- MIPS R3000A architecture documentation
- PSXRecomp, consulted as a technical reference for PlayStation static
  recompilation concepts
- Other emulator, recompilation, and reverse-engineering projects where
  specifically acknowledged

A reference being listed here does not imply that its source code is
incorporated into ProjectMoyle.

Any third-party source code actually incorporated into this repository
must be separately identified in THIRD_PARTY_NOTICES.md together with
its applicable license.
