# Reviewed development snapshot

This candidate preserves existing public history and imports only the file contents approved in import-manifest.json. Source labels identify inventory roles, not private Git ancestry. Hashes are file-content SHA-256 checksums.

The initial batch covers generic GTE arithmetic and R3000A proof analysis. The second batch adds independently authored boot/hardware/HLE interfaces, guarded dispatch, recompiler generators, factual compatibility metadata and synthetic tests. It does not claim a complete or playable game. Symbolic BIOS summaries are analysis assumptions, not original BIOS data.

Public licensing, attribution, CI, memory/GTE and CD backing corrections are preserved. CMake builds the public core, generators and a compile-only first-boot harness. Registered tests require no game input. Windows CNG overlay targets are gated to Windows.

Configure with CMake into a separate local build directory, for example `build/public`, then build and run CTest there. Python 3 and a C++20 compiler are required. Generated synthetic sources stay in the binary directory. Use an ignored build directory inside this checkout or a separate local directory; never commit or distribute generated real-input output.

Real first boot is opt-in: set `MOYLE_BUILD_FIRST_BOOT=ON` and `MOYLE_FIRST_BOOT_UNIT` to a locally generated PAL C++ unit inside that build directory. The unit must define `executeDirectTitle`; the harness requires external user-owned EXE, map and raw disc inputs at runtime. No real run is registered with CTest, no game input is supplied, and no real unit is generated by the default build. Optional LANGUAGE executor integration is not wired in this bounded batch. The generators can read external inputs; their real C++, reports, maps and disassembly must remain local.

The imported technical documents preserve historical findings and limitations. Commands mentioning private-worktree wrappers or tests outside this manifest are historical context, not commands supplied by this candidate. The CMake targets above describe the supported publication build.

The original GTE vector test is compiled but its execution is SKIPPED because its uncertain-provenance fixture is excluded. BZZ decoding, original translated routines, the game-specific initializer under human review, original assets, private research and generated real executors remain excluded. Excluded differential/copy-domain suites are not reported as passing.

Validation results are recorded in validation.json. Local build/admin artifacts must never be packaged for publication. Review manifest exclusions before considering further imports.
